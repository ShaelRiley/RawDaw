# Three CC Song Packs

These `.prdepack` archives contain 69 actual source-derived assets and one saved
estimated source drum measure each. Every pack is CC BY 3.0, with credit, source
links and processing changes inside its attribution/provenance records.

Each `_a.prdeproj` and `_b.prdeproj` is a new four-bar arrangement using that pack.
Run `make cc-demo` from the repository root to export and verify all six.

| Pack | A | B |
| --- | --- | --- |
| reach_out | B natural minor, 113 BPM | D major, 126 BPM |
| where_you_are_now | C natural minor, 100 BPM | C Dorian, 118 BPM |
| auld_lang_syne_bossa | F major, 130 BPM | D natural minor, 110 BPM |

All three are development/coverage-limited packs. Open hats and both tom slots
are unavailable; listening and complete tonal/source-alignment checks remain
open. Read [source credits and preparation](../docs/SONG_PACKS.md).
