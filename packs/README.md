# Four source Song Packs

These `.prdepack` archives contain 97 actual source-derived assets and one saved
estimated source drum measure each. The first three are CC BY 3.0. Parachute is
Shael Riley's user-authorized Suno source, with its separate rights declaration
preserved. Every pack retains credit and processing changes in its provenance.

Each `_a.prdeproj` and `_b.prdeproj` is a new four-bar arrangement using that pack.
Run `make source-demo` from the repository root to export and verify all eight.

| Pack | A | B |
| --- | --- | --- |
| reach_out | B natural minor, 113 BPM | D major, 126 BPM |
| where_you_are_now | C natural minor, 100 BPM | C Dorian, 118 BPM |
| auld_lang_syne_bossa | F major, 130 BPM | D natural minor, 110 BPM |
| parachute | B-flat natural minor, 165 BPM | B-flat harmonic minor, 132 BPM |

All four are development/coverage-limited packs. Open hats and both tom slots
are unavailable; listening and complete tonal/source-alignment checks remain
open. Read [source credits and preparation](../docs/SONG_PACKS.md).
